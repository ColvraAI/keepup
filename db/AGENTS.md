# db: the lever database, the product's moat

One JSON file per pattern and lever, as data. Ids are permanent, and a wrong lever is withdrawn, not deleted.
An agent's lever stays checked_by agent until a person opens its source. Open every source and read the number off the page.
Vendor and independent numbers stay in separate fields. Patterns under 85% precision are status info. See README.md and REVIEW.md.
