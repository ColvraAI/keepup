# Apriel Voice 27B Preview
An open model for speech, reasoning, and tool use from **ServiceNow**
Apriel Voice 27B Preview understands spoken requests, reasons over conversational context, and generates text responses and tool calls through a shared Gemma 4 backbone. It adds a speech interface while retaining text and image input capabilities. Pair it with an external speech synthesizer to build interactive voice assistants, customer support workflows, and spoken tool use.

## Model capabilities
Apriel Voice architecture
| Capability | What it supports |
|---|---|
| Speech understanding | Transcription, translation, and spoken question answering. |
| Reasoning and tool use | Following instructions, handling multi-step requests, and generating structured tool calls. |
| Multimodal context | Audio, text, images, and tool results in a shared conversation. |
| Voice applications | Text responses paired with external speech synthesis and application-managed turn-taking. |
The model supports transcription, speech translation, spoken instruction following, reasoning, and function calling. The application executes tools and returns their results to the conversation. Real-time voice interaction is supported by the application and serving stack; the checkpoint itself generates text and tool calls rather than native full-duplex speech.
A Whisper large-v3-turbo speech encoder connects to the Gemma 4 26B-A4B backbone through a learned projector. Training first aligns this speech interface, then adapts it with the backbone using speech tasks and text replay. Cross-entropy and teacher-distillation supervision vary by data source; the technical report describes the full recipe.
### Long audio
The processor automatically splits longer 16 kHz mono recordings into 30-second chunks. In testing, we observed good performance on continuous recordings up to around 30 minutes. Longer recordings are supported, but performance can decline as duration grows; thinking mode is recommended for longer audio.
Audio chunks and the rest of the conversation share the total context budget. Practical input length also depends on GPU memory and the encoder cache. The serving examples below include settings for 30-minute audio, with optional settings for one-hour input.
## English results
Apriel Voice achieves **51.27% EVA-A**, **74.13% EVA-X**, and **65.51% τ-Voice task success**, with **1.91 seconds** mean τ-Voice response latency. On LibriSpeech, word error rate is **2.23% on test-clean** and **5.15% on test-other**; lower WER is better.
