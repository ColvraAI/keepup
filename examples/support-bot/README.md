# support-bot

A fake product to try keepup on. It isn't a real company's code, and nothing here runs in production. It uses AI the way many small products do: a router that only picks a label, a long system prompt sent on every call, and a nightly job that calls the API one ticket at a time.

To try keepup on it, copy this folder into a repo of its own, then run `/keepup` there, or add `.github/workflows/keepup.yml`.
